2. Скопируйте два значения:

```js
window.KONTREIT_CONFIG = {
  supabaseUrl: 'https://xxxxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOiJIUzI1NiIsInR5cCI6...',
```

4. **Commit changes** → подождите минуту, обновите сайт.

> **Никогда** не вставляйте в `config.js` ключ `service_role` (в разделе API он тоже есть). Этот ключ обходит все правила доступа и должен использоваться только на сервере.

## Шаг 7. Рабочий режим и обновления онлайн

**Как править сайт.** В GitHub: откройте файл → карандаш → правите → **Commit changes**. Через 1–2 минуты изменения на сайте. История версий сохраняется автоматически — любую правку можно откатить.

**Как править документы.** `Документы_Контейнерный_Союз.md` — обычный текст в формате Markdown. Правьте формулировки прямо на GitHub (кнопка «Preview» показывает, как будет выглядеть). Каждое изменение — коммит с комментарием вроде «Устав, ст. 11: изменить кворум Совета». Так формируется протокол изменений: кто, когда и что поменял.

**Как менять тарифную сетку.** Два пути:
- через платформу: Совет перевозчиков → «Внести предложение» → (Администрация) «Утвердить в переходный период» — тариф обновится и на сайте, и в базе;
- напрямую в базе: Supabase → Table Editor → `tariff` → отредактировать строку → на сайте нажать «⟳ Обновить данные из базы».

**Ежедневный ритуал (2 минуты):**
1. открыть `https://<логин>.github.io/container-union/` — проверить, что сайт жив;
2. Supabase → Table Editor → `applications` — посмотреть новые заявки;
3. Supabase → `carriers` — посмотреть, сколько верифицированных набралось (цель — 50).

**Раз в 3–4 дня** открывайте проект в консоли Supabase: бесплатные проекты засыпают после ~7 дней без активности. Как альтернатива — бесплатный ping через GitHub Actions (cron раз в 2 дня на адрес `${SUPABASE_URL}/rest/v1/tariff?select=id`, ключ `anon`).

**Раз в неделю** выгружайте резервную копию: Supabase → Table Editor → нужная таблица → Export → CSV. Складывайте в тот же репозиторий или в облачный диск.

## Когда наберётся 50 перевозчиков

Порог достигнут → на вкладке «Совет перевозчиков» активируется кнопка **«Назначить выборы Совета»**:

1. нажатие фиксирует даты: выдвижение кандидатов — 20 дней, голосование участников — 15 дней;
2. по итогам голосования Администрация публикует избранный состав (9 мест), переходный период завершается;
3. с этого момента тарифные решения принимаются только голосованием Совета: 6 из 9 (тарифы), 5 из 9 (работа платформы), 7 из 9 (Устав), кворум — 7 членов.

До этого момента платформа остаётся полностью рабочей: калькулятор, реестр, рейтинг, биржа и открытые обсуждения — действуют.

До этого шага база работает в режиме прототипа: правила доступа открыты. После — изменения в базе может делать только Администрация, а все остальные пользуются платформой в режиме чтения и публичной записи (регистрация, заявки, ставки).

1. **Создайте аккаунт Администрации.** Supabase → **Authentication → Users → Add user**:

2. **Закройте свободную регистрацию.** Supabase → **Authentication → Sign In / Providers → Email** —

4. **Выдайте себе права куратора.** В том же SQL Editor выполните (подставьте свой e-mail):
   ```sql
   insert into curators (user_id, email, role)
   select id, email, 'admin' from auth.users where email = 'ВАШ_EMAIL@пример.ру'
   on conflict (user_id) do nothing;
   ```
5. **Проверьте на сайте.** Откройте сайт → нажмите **«Вход для Администрации»** в шапке → введите

| Действие | Без входа (гость) | Куратор (после входа) |
|---|---|---|
| Смотреть реестр, тариф, заявки, решения | ✔ | ✔ |
| Регистрация перевозчика, заявка, ставка | ✔ (статус «ожидает верификации») | ✔ |
| Верификация, изменение статусов | ✘ — база отклонит | ✔ |

| Чтение заявок на верификацию (с ИНН) | ✘ | ✔ |

Проверка, что защита включилась: выйдите из аккаунта (кнопка «Выйти») и попробуйте верифицировать перевозчика — появится сообщение «доступно только куратору», а прямой запрос к базе вернёт 401.

## Шаг 9. Keep-alive: чтобы бесплатная база не засыпала — ✅ ВЫПОЛНЕНО (16.10.2026)

Бесплатный проект Supabase приостанавливается после ~7 дней без запросов. Пинг раз в 2 дня это исключает.

**Вариант А (GitHub Actions).** Нужен файл `.github/workflows/keepalive.yml`.
Проще всего — по ссылке-заготовке (файл создаётся сразу с содержимым, останется нажать «Commit changes»):
ссылка указана в сообщении к этому шагу; содержимое файла — `tools/keepalive.workflow.yml`.
Проверка: вкладка **Actions → keep-alive Supabase → Run workflow** — покажет версию тарифной сетки и счётчик перевозчиков.

**Вариант Б (внутри Supabase).** SQL Editor → выполнить один раз (нужны расширения pg_cron и pg_net —
включите их в Database → Extensions):

```sql
select cron.schedule('keep-alive', '0 6 */2 * *', $$
  select net.http_get(
    url := 'https://nciyhaghjqddkqzuimff.supabase.co/rest/v1/tariff?select=id',
    headers := '{"apikey":"sb_publishable_vL0U2ble-aE4F5juUPNXpQ_raUy-eaR"}'::jsonb
  );
$$);
```

**Вариант В (внешний мониторинг).** Зарегистрируйтесь на UptimeRobot (бесплатно) → Add monitor → HTTP(s) →
адрес `https://nciyhaghjqddkqzuimff.supabase.co/rest/v1/tariff?select=id`, Custom HTTP header:
`apikey: sb_publishable_vL0U2ble-aE4F5juUPNXpQ_raUy-eaR`, интервал 3 дня. Бонус: придёт письмо, если база или сайт недоступны.

## Дизайн-обновление (16.10.2026) — ✅ ВЫПОЛНЕНО

Коммит **5ee084e**, проверено на живом сайте: **6/6** (дизайн) + **5/5** (защита) + **12/12** (сценарий гость/куратор), 0 ошибок JS.

1. **Логотип-контейнеровоз.** Корпус, надстройка, труба и волны; буквы К и С — контейнеры на палубе. При наведении из К разворачивается «онтейнерный», из С — «оюз»: получается «Контейнерный Союз». На телефоне — касание разворачивает и сворачивает. Логотип обновлён в шапке, строке вкладок, футере, на «О платформе» и в иконке браузера. Буквы появляются по одной с задержкой, при убирании курсора сворачиваются в обратном порядке.
2. **Меню без бегунка.** Горизонтальная прокрутка вкладок убрана совсем: на узких экранах вкладки переносятся на вторую строку, названия сокращаются («Калькулятор», «Перевозчики»), появляется подсказка «← свайп →» на сенсорных экранах. Добавлены клавиши ← и → и свайп по содержимому для перехода между вкладками.
3. **Сайт стал живым:** лента событий под шапкой (тариф, ДТ, «Платон», реестр, биржа — обновляется из базы), появление карточек при прокрутке, отклик кнопок (рябь), полоса прогресса чтения, кнопка «наверх», анимация появления вкладок, пресеты плеч в калькуляторе («Новороссийск → Москва» и др.), автоматический пересчёт ставки при любом изменении поля, живой поиск по реестру (название, город, регион, ИНН), подсказка о прокрутке широких таблиц, копирование адреса сайта и короткой ссылки в один клик, кнопки закрытия уведомлений кликом, Esc закрывает окна.
4. Учитывается системная настройка «уменьшить движение» (prefers-reduced-motion): анимации отключаются для тех, кому они мешают.
