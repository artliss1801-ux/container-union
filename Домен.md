**Честно о моих возможностях:** зарегистрировать домен и оплатить его я не могу — регистрация оформляется на ваше имя (для .ru регистратор попросит паспортные данные) и требует оплаты картой. Это единственный платный элемент всего проекта: 200–350 ₽ в год. Всё остальное — бесплатно.

**Что я сделаю сам, как только домен будет куплен:** подключу его к сайту (настройки GitHub Pages, HTTPS, автоперенаправление www) — займёт 5 минут. От вас нужен будет только доступ (токен) и добавление DNS-записей в кабинете регистратора, которые я подготовлю ниже.

## 3. Как зарегистрировать домен (5 минут)

1. Откройте **reg.ru** (или nic.ru) → поиск **cont-union.ru** → «Зарегистрировать».
2. Выберите срок — 1 год. Для .ru потребуется указать паспортные данные (требование регистратуры домена .ru) и подтвердить e-mail.
3. Оплатите картой (200–350 ₽). Домен активируется в течение нескольких минут, иногда до нескольких часов.
4. Если хотите и .com — повторите для cont-union.com (~1000 ₽/год).
5. Напишите мне: «домен куплен» — я сразу дам точные DNS-записи и переключу сайт.

## 4. DNS-записи (можно поставить заранее, вреда не будет)

В кабинете регистратора → DNS-записи домена:

```
Тип    Имя    Значение
A      @      185.199.108.153
A      @      185.199.109.153
A      @      185.199.110.153
A      @      185.199.111.153
AAAA   @      2606:50c0:8000::153
AAAA   @      2606:50c0:8001::153
AAAA   @      2606:50c0:8002::153
AAAA   @      2606:50c0:8003::153
CNAME  www    artliss1801-ux.github.io
```

Это официальные адреса GitHub Pages. Записи `A` и `AAAA` — для самого домена `cont-union.ru`, `CNAME` — для `www.cont-union.ru`.

## 5. Финальный шаг (сделаю я или вы вручную)

- Репозиторий → **Settings → Pages → Custom domain** → ввести `cont-union.ru` → **Save**;
- дождаться появления зелёной галочки DNS (от 10 минут до 24 часов — зависит от регистратора);
- поставить галочку **Enforce HTTPS** (сертификат GitHub выдаст бесплатно, автоматически).

После этого сайт откроется и как `https://cont-union.ru`, и как `https://www.cont-union.ru`, а старые адреса будут автоматически перенаправляться на новый домен.
