## 3. Зона DNS — как настроено

```
cont-union.ru.        IN SOA   ns1.jino.ru hostmaster@jino.ru (…)
cont-union.ru.        IN A     185.199.108.153
cont-union.ru.        IN A     185.199.109.153
cont-union.ru.        IN A     185.199.110.153
cont-union.ru.        IN A     185.199.111.153
www.cont-union.ru.    IN CNAME artliss1801-ux.github.io.
cont-union.ru.        IN NS    ns1.jino.ru / ns2 / ns3 / ns4
```

Осталось только одно техническое обстоятельство: **старый адрес `81.177.141.15` в кэшах DNS**. Записи на
серверах Джино уже заменены, но у части провайдеров и браузеров прежний ответ держится до истечения TTL
(в зоне стоял `25600` ≈ 7 часов). У всех, кто открывает домен после этого срока, он открывается сразу;
на работу сайта по домену это не влияет — GitHub отдаёт его уже сейчас.

Проверить самому: `nslookup cont-union.ru 8.8.8.8` → должны быть адреса `185.199.10x.153`.

## 4. Чего больше делать не нужно

| Что | Кто делает |

| Продление сертификата HTTPS | GitHub автоматически, бесплатно, раз в 90 дней |

| Продление домена | владелец домена в панели Джино, примерно 300 ₽/год |
| Правки DNS | больше не требуются; при смене хостинга — те же четыре A и CNAME www |

## 5. Если понадобится изменить привязку

- **Сменить адрес сайта на другой домен** — сообщить агенту: он переключит `custom domain` через API и
  перепроверит HTTPS и редиректы.
- **Почта на домене** — сейчас MX-записей нет, домен используется только для сайта. Если понадобится
  почта вида `info@cont-union.ru`, её заводят в панели Джино или у почтового провайдера, добавляя MX-записи;
  на работу сайта это не повлияет.
- **Wildcard-поддомены** — если когда-нибудь понадобятся (`cabinet.cont-union.ru` и т. п.), каждое имя
  добавляется отдельной записью; «звёздочку» возвращать не нужно.

## 6. Как это выглядело до привязки (для истории)

Домен куплен на «Джино», делегирован на `ns1–ns4.jino.ru`. До 22.10.2026 зона отдавала парковку
регистратора: `cont-union.ru A 81.177.141.15` и wildcard `*.cont-union.ru A 81.177.141.15` — на любой
запрос приходила заглушка «Домен зарегистрирован через Джино» (ответ 404 от nginx).

Порядок привязки, который сработал: **сначала DNS, потом домен в настройках сайта**. Обратный порядок
сломал бы сайт: GitHub начал бы перенаправлять рабочий адрес на домен, который показывает заглушку.
22.10.2026 владелец внёс записи в панели Джино, после чего домен был включён и проверен — см. разделы 2–3.
