## 2. Свой домен cont-union.ru — куплен на «Джино», делегирован ✅

Проверено 16.10.2026: домен уже работает в интернете — DNS-серверы Джино (`ns1-4.jino.ru`) приняли его,
но сейчас он показывает **заглушку «Домен зарегистрирован через Джино»** (адрес 81.177.141.15).
Осталось заменить адрес на серверы GitHub — это три минуты в панели Джино.

### Что сделать в панели Джино (по официальной инструкции Джино)

1. Откройте контрольную панель → раздел **«Домены / Управление»** (меню «Аккаунт → Домены»).
2. У домена `cont-union.ru` нажмите **«Настройки»** → вкладка **«DNS»**
   (на некоторых экранах кнопка называется **«Управление DNS»**).
3. В строке `IN A` (адрес `81.177.141.15`) нажмите **«Редактировать»** и поставьте `185.199.108.153`.
4. Кнопкой **«Новая DNS-запись»** добавьте ещё три адреса — тип **A**, имя пустое или `@`:
   `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
5. Добавьте запись для www: тип **CNAME**, имя `www`, значение `artliss1801-ux.github.io`.
6. Сохраните. Изменения обычно вступают в силу за 15–60 минут.

### Если панель снова выдаст ошибку сервера

Такое бывает в первые сутки после регистрации. Что делать по порядку:
1. Подождите 2–3 часа и обновите страницу; попробуйте другой браузер или режим инкогнито.
2. Если ошибка сохраняется — напишите в поддержку Джино из панели: «Не открывается управление DNS домена
   cont-union.ru, ошибка сервера. Нужно изменить A-записи и добавить CNAME». Отвечают обычно за несколько часов.
3. Пока вопрос решается, сайт полностью работает по адресам ниже — ничего не сломано.
